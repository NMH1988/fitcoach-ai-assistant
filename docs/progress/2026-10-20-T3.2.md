- **Why:** several phrasings find passages one phrasing misses (`test_a_rewrite_finds_chunks_the_question_alone_misses`). The question is searched too, so a rewrite that loses part of it cannot hide what the question alone finds. The distance limit applies to each query, so a rewrite that drifts towards the domain can still bring an off-topic question to the answer model, whose prompt declines it (`test_a_chunk_found_only_by_a_rewrite_counts`); the owner kept this after the live check, where an off-topic question's rewrites stayed off topic. Filters are built in code from checked values, so model text never reaches Chroma. Only format problems fall back; a key, credit or rate-limit error would hit the answer call too, so it ends the turn.
