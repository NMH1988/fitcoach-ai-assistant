- **What:**
  - `src/tracing.py`: `configure_tracing()` (run by `observability.configure_logging()`, so by the page and every script): off unless `FITCOACH_TRACING` and `LANGSMITH_API_KEY` are both set, and then LangSmith is turned off globally; on, one `langsmith.Client` for the EU endpoint with `mask()` as its anonymizer and no runtime info, installed as LangSmith's global client (built once per key). `mask()`: an allowlist by key that keeps the shape, token counts, counters, LangGraph's node fields, the model name, the app's tool names, statuses, kinds and codes, and `turn_id`; every other text and number becomes `[masked]`, tool arguments whole, an error its class name, a key that is not an identifier `[masked key N]`.

  - `observability`: keeps the `langsmith` logger at WARNING. `pyproject.toml`: `langsmith==0.14.12` pinned (MIT).

- **Why:** LangSmith is configured once, globally, rather than passing a tracer to each graph: then every run LangChain traces goes through the masking client, including runs a later ticket adds, and LangSmith's own environment flag, which traces with no masking (compliance run 1, finding 1; confirmed in the Research phase), is switched off in the same place. The anonymizer, not `hide_inputs`/`hide_outputs`, because it also covers each run's metadata (the review's user IDs) and error (an exception's message can quote the question). An allowlist by key, as for the log lines: anything not named stays out.
