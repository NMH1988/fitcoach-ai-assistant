- **Why:** the reviewer saw LangSmith used for masked traces only. Experiments put the evaluation, which the project already runs (T6.1, T8.4, T9.10), into LangSmith, where runs of different models or commits can be compared question by question; a masked experiment would show scores only, so the evaluation's own runs, on the owner's questions and a made-up profile, are sent unmasked. The script keeps its own loop rather than LangSmith's `Client.evaluate()`, which wraps the target with `traceable` and logs a target's error with its message and traceback through LangSmith's logger (`langsmith/evaluation/_runner.py`), against the log rules; a tracer in the turn's callbacks also keeps LangChain from adding the global (masked) one, so a turn goes to one project only.
