## 2026-10-19 · T2.1 Source manifest, download script, attribution · #26 (closes #4)
- **Brief:** core requirements 1 and 3 (a relevant, focused knowledge base); AC-14. The strict licence checks serve the copyright policy (beyond the brief, owner's request).
- **What:**
  - `data/sources.json` (new): the 21 approved articles (#1-#20 and the correction #18a) with title, authors, year, journal, DOI, PMCID, DOI URL, licence, licence URL, copyright notice, evidence tier and topics. Title, authors, DOI and the copyright notice (word for word) come from each article's own JATS front matter, read through the Europe PMC REST API; tiers from `docs/SOURCES.md`; topics as proposed and approved by the owner.
  - `src/rag/sources.py` (new): `Source` (Pydantic; empty, unknown or inconsistent fields are rejected: URL must be the DOI link, licence URL must match the licence, topics and tiers from config), `load_manifest()` (also rejects duplicate IDs, PMCIDs or DOIs), `read_license()` / `check_article()` (the licence and DOI check), `render_attribution()`.
  - `scripts/download_sources.py` (new): fetches each article's `fullTextXML` from the Europe PMC REST API with a descriptive User-Agent, a 1 s pause between requests, a 30 s timeout and a 10 MB cap; keeps a file in `data/raw/<PMCID>.xml` only if `check_article()` accepts it; reports refused and failed articles and exits with 1 if there are any. Standard library `urllib`, no new dependency.
  - `scripts/generate_attribution.py` (new) and `ATTRIBUTION.md` (new, generated): one CC BY credit per source, following the template in `docs/SOURCES.md`.
  - `src/config.py`: paths (manifest, `data/raw/`, `ATTRIBUTION.md`), `TOPICS`, `EVIDENCE_TIERS` and the download settings.
  - Tests: `tests/test_sources_manifest.py` (the manifest against the Approved tables of `docs/SOURCES.md`: IDs, PMCIDs, years, licences, tiers; no empty field; validation cases), `tests/test_sources_license.py` (made-up fixture XML in `tests/fixtures/jats/` and inline snippets: every licence markup, CC BY with a CC0 data waiver, CC0 alone, NC/ND/SA/mixed/unknown/missing refused, licence and DOI must match the manifest, the expat version), `tests/test_download_sources.py` (mocked HTTP client and sleep: the URLs used, the User-Agent and timeout, the pauses, refused files not written and reported, older copies deleted, failures reported, exit codes), `tests/test_attribution.py` (each element of an entry, escaping, and the committed file equal to the generated one). 221 tests pass.
  - Docs: `docs/SOURCES.md` (#1 now has PMCID PMC13665703, checked on its Europe PMC XML), `docs/ARCHITECTURE.md` sections 3, 4 and 14, `docs/SECURITY.md` (two threat rows), `docs/TESTING.md` (the real download run), `CLAUDE.md` (commands), plan (T2.1 in review, O4 done as not needed).
- **Why:** the licence is read from the article itself, not from aggregator metadata (copyright policy rule 4), and the check sits in `src/` so T2.2 can reuse it. The download URL is built from the validated PMCID rather than stored in the manifest, so the manifest cannot send the script to another host. Checking the DOI as well catches a wrong PMCID. The committed `ATTRIBUTION.md` is compared with the generated text in a test, so it cannot drift from the manifest.
- **Decisions & gotchas:**
  - Owner's choices (2026-10-19): Europe PMC now has source #1 (PMC13665703, same DOI, CC BY 4.0), so O4 is not needed and the hand-saved fallback was dropped; the topics per source; Claude ran the real download once (21 of 21 saved, recorded in `docs/TESTING.md`).
  - Licence markup differs between publishers: `license/@xlink:href`, `ali:license_ref`, or only an `ext-link` inside `license-p`; all three are read, plus plain-text URLs. Six BioMed Central articles also link CC0 1.0 in the licence block (for their data): CC BY wins over CC0 when both appear. Any other Creative Commons licence in the block refuses the whole file, as do two different CC BY versions.
  - Only the article's own `front/article-meta/permissions` counts, not a `sub-article`.
  - To check the markup before writing the code, the 21 XML files were fetched once through the Europe PMC REST API into a temporary folder outside the repo (2 s pause); nothing from them is committed except the front-matter fields in the manifest.
  - Author names are the article's own (given names plus surname), so some keep full stops after initials and some do not, as each publisher writes them.
  - #4 is listed as 2024 (first published 2024; volume 2025), as in `docs/SOURCES.md` and its copyright notice.
  - Code review (round 1, before the PR): the script no longer follows redirects (urllib's default follows them to any host, which could have reached a publisher's website, rule 10); a licence ID in `license/@xlink:href` or `ali:license_ref` that is not Creative Commons now refuses the file even if a CC BY URL appears in the text ("unknown licence = excluded"); wording that contradicts CC BY ("NonCommercial", "NoDerivatives", "ShareAlike", "All rights reserved") refuses it too (none of the 21 approved licence blocks contain it, checked); CC0 tested through `check_article()`; duplicate DOIs compared without case; a file that cannot be written is reported, not a crash. `/security-review`: no findings.
