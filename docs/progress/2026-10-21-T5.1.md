- **Why:** one recorder passed down the turn keeps the calls in order and survives an error (the owner's default: tokens spent before an error count). The cost is computed once at the end of the turn and stored, so reruns never wait on the network, and a failed read only marks that turn "price unknown". The embedding count is returned with the vectors, never kept on the client, which `st.cache_resource` shares across sessions.
