- **What:** every prompt has a version, the first 12 hex characters (`config.PROMPT_VERSION_LENGTH`) of the SHA-256 of the exact text the model receives (`chat.prompt_version()`, `chat.Prompt`, whose version is worked out from its text so the two cannot disagree); `graph.load_prompt()` returns a `Prompt`. `graph.load_turn_prompts()` reads a turn's prompt files in the order the prepare node read them and returns `graph.TurnPrompts` (the joined answer prompt and the query translation prompt); `chat.run_turn()` calls it once before the graph runs and passes the prompts, or the error reading them raised (a `PromptMissingError`, or any other from a bug, so `run_turn()` still never raises), in `TurnContext.prompts`; the prepare node sends that text (and reads the files itself only for a graph run without `run_turn()`). The versions go on the run's metadata (`tracing.run_metadata(turn_id, prompts)`, which takes only the prompt version keys, through `graph.run_config()` and `Conversation.config()`/`run()`, the trace's root), on `TurnResult.prompts` and on the `turn` log line (`prompt_answer`, `prompt_query`). `tracing.mask()` keeps a value under `prompt_answer`, `prompt_query` or `prompt_review` only when it is exactly 12 lowercase hex characters. The weekly review: `ReviewContext.prompt` is a `Prompt`; the drafting run's metadata and `weekly_review` line carry `prompt_review` (a decision none), and `reviews.save_review()` takes a required `prompt_version` (checked by `values.prompt_version()`), stored by migration 7 (`schema._V7`: `ai_reviews.prompt_version`, `unknown` for older rows, a CHECK for 12 hex characters and a trigger that refuses `unknown` on a new row) and exported. The evaluation: `scripts/run_evaluation.py` reads the versions as the run starts (a missing prompt now stops the run before the first question, exit 1) and writes them to the results file (`prompts`) and the experiment's metadata, with `prompts_changed_during_run` (`eval_results.prompts_changed_during_run()`) and a printed note when a turn ran with others. Docs: ARCHITECTURE ("Prompt versions", the logging paragraph, the `ai_reviews` row), SECURITY (the log fields, the kept trace keys and the mask's limits), TESTING ("Prompt versions (T10.4)": how to compare them), `.claude/rules/security-privacy.md` (the kept keys).
