- **What:**
  - `src/observability.py` (new): `JsonFormatter` (one JSON line with `ts`, `level`, `logger`, `event` and only the fields in `ALLOWED_FIELDS`; message arguments and exceptions are never written) and `configure_logging()` (one handler on the `src` logger, stderr, no file, level from the new `config.LOG_LEVEL`, `propagate` off).
  - `src/chat.py`: `TurnResult.turn_id` (UUID4); `run_turn()` writes one INFO `turn` record on every ending and the WARNINGs `llm_error`, `guard_rejected` and `tool_failed`; T1.8's catch-all line is now the ERROR `turn_error` with a `diagnostic` field; `run_turn(prices=...)` for the cost; `on_chunks` is wrapped to count the chunks.
  - `src/usage.py`: `PriceCache.peek()`. `views/chat.py` passes `usage.PRICES.peek`; `scripts/run_evaluation.py` passes the prices it read.
  - `app.py` and the `main()` of all eight scripts call `configure_logging()` first.
  - Tests: `tests/test_observability.py` (formatter, handler, canary tests for eleven endings, wiring), `tests/test_chat.py` (turn records and warnings; T1.8's tests adapted), `tests/test_usage.py` (`peek`), `tests/conftest.py` (removes the handler after each test).
  - Docs: `docs/SECURITY.md` (a threat row: what is logged, what never is), `docs/ARCHITECTURE.md` (folder layout, section 10 "Logging"), `.claude/rules/security-privacy.md` ("Logs"), the plan.
- **Why:** the reviewer found that nothing logged: a guard rejection, a rate limit, a model error or a failed tool left no trace, and `LLMError.diagnostic` was never written. One record per turn with a turn ID, and no text the user or the model wrote, gives a trace that is safe to keep and that T9.8 can match to a LangSmith trace.
- **Decisions & gotchas:** owner's choices (2026-10-26): `cost_usd` uses only the prices already read, because reading them is a network call that `views/chat.py` makes after the answer is in the history (a click during it would drop the answer), so the first turn of a process logs `null`; `source_ids` are the sources of the chunks the answer model got; `configure_logging()` in all eight scripts. A tool the model made up is logged with a `null` name (its name is the model's text). `duration_ms` covers the whole turn, the paced display of the answer included. A turn that Streamlit interrupts (a rerun or stop, a `BaseException`) writes no `turn` record. A `ValueError` for an unknown language is a bug in the caller and is raised before any record. With `propagate` off, `caplog` cannot see the app's records once `configure_logging()` has run, so `tests/conftest.py` removes the handler after every test. The evaluation script now prints JSON lines on stderr beside its output.
