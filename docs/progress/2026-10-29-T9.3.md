- **What:**
  - `src/agent/search.py` (new): `search_knowledge_base` for the model (`SearchArgs`, one query of 1 to `SEARCH_QUERY_MAX_CHARS` characters), `run_search()` (query translation and hybrid search through `chat.find_chunks()`, the chunks back in a `<sources>` tool message), and `SearchLog`, the turn's searches and labelled chunks.

  - `views/details.py`: each search of the last turn that reached the model (the query, its rewrites, the filters, the notes, the passages found with their labels), or that the model did not search; the card counts the searches and their queries.
  - `scripts/run_evaluation.py`: every search's chunks in label order, a `searches:` line in the summary, each search in the report; no plan flags.
  - Tests: `tests/test_agent_search.py` (new); `ScriptedChatModel.search_first` (on by default: with the search offered and none run yet, the fake searches the question) and `FailsAfterFirstCall` in `tests/fakes.py`; the graph, chat, tool-loop, usage, injection, observability (two new canary endings), evaluation and AppTest suites adapted. 4,029 tests pass after merging `main` with T9.21 (whose test of the git reads counted one model call per question; since T9.3 a question is a search and an answer call).
