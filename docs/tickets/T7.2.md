**Notes:** the knowledge base stays English. Since T3.8 (2026-10-21) the English rewrites widen the search but do not decide whether the sources cover a question: only the question's own vector does, against `RETRIEVAL_MAX_DISTANCE`, which was calibrated on English questions. A German question whose own wording is further than the limit from the English chunks gets `NO_SOURCES_MESSAGE` even when its English rewrites come close, so the second criterion alone does not make German retrieval work. T3.8's live check records one or two German questions; how T7.2 handles this (e.g. a limit measured on German questions, or letting the English rewrites decide for a German question) is the owner's choice. Owner's choice (2026-10-21): measure first; the five German questions' own nearest chunks were at 0.319-0.617, all within 0.62, so the gate stays as it is. Other choices at the start: the language parts are fixed text the code joins to the end of the answer prompt (not a block in the user message); the PDF writes every app text in the language (tools' messages, notes, credit lines and the font licence stay English); the German language part was drafted in German by the owner and translated into English (the repo is English).
