- [x] `python -m scripts.run_evaluation --langsmith` runs the same turns as today as a LangSmith experiment on that dataset, named with the git SHA, the model and the language, and attaches per answer the found and cited results, the expectation check and, with `--score`, DeepEval's faithfulness and answer relevancy as feedback scores; the local report and results `.json` are written as before, and `check_eval_baseline` stays the gate - unit tests with a fake client and a mocked chat turn. Done: `--langsmith` in `scripts/run_evaluation.py`; the experiment `fitcoach-eval-<commit>[-dirty]-<model>-<language>-<time>` on the dataset; each turn traced into it through `tracing.RunTrace` and linked to its example; feedback `turn_kind`, `expected_found`, `expected_cited` or `cites_nothing`, `unexpected_citations`, and with `--score` `faithfulness` and `answer_relevancy` with the judge's reason (`tests/test_run_evaluation.py`: `test_langsmith_records_the_run_as_an_experiment_on_the_dataset`, `test_langsmith_with_score_sends_the_scores_and_the_judge_s_reasons`; `tests/test_experiments.py`: the name, the project, the feedback); the report and results file are written as before (the same test) and the baseline check is unchanged.

Done: the owner chose (a) (2026-11-12); the experiments' client masks only a run's error, to its class name, and is never installed globally (`test_the_experiments_client_is_unmasked_but_never_the_global_one`, `test_a_failed_experiment_turn_sends_no_reply_or_traceback`; code review round 1); an experiment turn goes unmasked to its own project, linked to its example, and nothing reaches the app's project (`test_an_experiment_turn_goes_unmasked_to_its_project_only`); an app turn after it in the same process is still masked, the canary profile included (`test_the_app_s_turns_stay_masked_after_an_experiment_in_the_same_process`); only `src/tracing.py` and `src/experiments.py` import `langsmith`, and only the evaluation script imports `src/experiments.py` (`test_only_the_tracing_module_uses_langsmith_and_nothing_retries`, `test_only_the_evaluation_script_uses_the_unmasked_experiments`); the rule ("The one unmasked path") and `docs/SECURITY.md` (a row of its own) say so.
